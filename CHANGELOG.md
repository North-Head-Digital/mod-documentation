# FCRO Documentation Changelog

All notable changes to the FCRO documentation will be documented in this file.

## [2.5] - 2025-12-05

### Added
- **Vision & Spotting System**: Complete documentation of human, vehicle, and aircraft detection mechanics
- **Faction Weapon Comparisons**: Comprehensive side-by-side comparisons:
  - Submachine guns by nation
  - Bolt-action rifles by nation
  - Machine guns by nation
  - Sniper rifles by nation
  - Anti-tank rifles by nation
  - Tank gun penetration summary

### Enhanced
- Cross-faction balancing insights
- Tactical implications of spotting changes
- Detection formulas and examples

## [2.0] - 2025-12-05

### Added
- **Armor Penetration Tables**: Detailed penetration values for all major tank guns
  - German guns (75mm KwK 42, 88mm KwK 36/43, 128mm PaK 44)
  - Soviet guns (76mm F-34, 85mm ZiS-S-53, 100mm D-10T, 122mm D-25T)
  - American guns (75mm M3, 76mm M1A1, 90mm M3)
  - British guns (QF 17-pounder with APDS)
- **Ammunition Types**: Complete AP shell type breakdown with slope modifiers
- **Grenades & Explosives**: Hand grenades, satchel charges, and mines with blast radii
- **Veterancy System**: Experience levels and bonuses
- **Vehicle Damage System**: Crew kill chances by shell caliber

### Enhanced
- Post-penetration damage mechanics
- Slope performance by ammunition type
- Blast energy calculations

## [1.1] - 2025-12-05

### Added
- Complete accuracy curves for all weapon classes
- AI behavior parameters (firing timeouts, spread tolerance)
- Detailed flamethrower specifications (infantry and vehicle)
- Expanded tank gun section with Japanese and Finnish equipment

### Enhanced
- Weapon pattern documentation with file paths
- Range macro system explanation
- Real-world distance conversions (8:1 scale)

## [1.0] - 2025-12-05

### Initial Release
- **Infantry Small Arms**: Rifles, sniper rifles, submachine guns, machine guns, pistols
- **Anti-Tank Weapons**: AT rifles, bazookas, panzerfausts, rifle grenades
- **Flamethrowers**: Infantry and vehicle-mounted variants
- **Mortars**: Light, medium, heavy, and super-heavy classifications
- **Rocket Artillery**: Katyusha, Nebelwerfer, Calliope systems
- **Tank & Artillery Guns**: All major factions' vehicle weapons
- Quick reference range summary table
- Mod philosophy and design goals

### Philosophy
- 20-50% range increases across all weapons
- Increased lethality and damage
- Improved accuracy curves
- Enhanced AI behavior
