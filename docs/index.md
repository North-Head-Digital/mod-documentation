# FCRO - Frontlines Combat Realism Overhaul

Welcome to the complete documentation for **Frontlines Combat Realism Overhaul (FCRO)**, a comprehensive realism modification for Gates of Hell: Ostfront and Their Finest Hour DLC.

## What is FCRO?

FCRO is a total combat realism overhaul that fundamentally transforms the Gates of Hell combat experience by adjusting weapon ranges, accuracy, damage values, and game mechanics to create more realistic and tactically engaging battles.

### Mod Philosophy

FCRO increases engagement ranges by **20-50%** to create more realistic combat distances while maintaining weapon role balance. Damage has been significantly increased to make combat more lethal and decisive, rewarding tactical positioning and smart unit usage.

**Important Scale Note:** Gates of Hell uses approximately an 8:1 scale ratio. A 180m in-game range represents approximately 1440m real-world distance.

## Key Features

- **Extended Weapon Ranges**: All weapons receive 20-50% range increases to match historical capabilities
- **Increased Lethality**: Higher damage values create more decisive and realistic combat outcomes
- **Enhanced Accuracy Systems**: Improved accuracy curves with proper degradation at range
- **Realistic Armor Penetration**: Detailed penetration values based on historical data
- **Improved AI Behavior**: Better firing timeouts and spread tolerances for more intelligent combat
- **Complete Vehicle Damage System**: Realistic damage mechanics for all vehicle components
- **Advanced Spotting Mechanics**: Realistic vision and detection distances for infantry, vehicles, and aircraft

## What's Modified

FCRO comprehensively modifies:

- **Infantry Small Arms**: Rifles, sniper rifles, submachine guns, machine guns, pistols
- **Anti-Tank Weapons**: AT rifles, bazookas, panzerfausts, rifle grenades
- **Support Weapons**: Flamethrowers, mortars, rocket artillery
- **Vehicle Weapons**: Tank guns, artillery pieces, vehicle-mounted weapons
- **Combat Mechanics**: Veterancy system, damage models, accuracy curves
- **Detection Systems**: Vision ranges, spotting mechanics, camouflage values
